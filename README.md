# ARD — Aorin Render Distance（描画距離突破）

**Minecraft統合版のエンティティ描画限界（約64ブロック）を突破するレンダリング技術**

碧臨重工（AORIN INDUSTRY）が開発した、エンティティを数百ブロック先からでも
表示させるためのオープンな実装手法です。列車アドオンのために開発しましたが、
モブ・乗り物など任意のエンティティに適用できます。

*ARD (Aorin Render Distance) is an open technique to render entities far beyond
Bedrock's ~64 block entity culling limit, developed by AORIN INDUSTRY.
Documentation is currently in Japanese.*

## 仕組み（概要）

統合版はエンティティ本体の位置が約64〜73ブロック離れると描画を打ち切ります。
ARDはこれを逆手に取ります：

1. プレイヤーの近くに透明な「ゴースト」エンティティを係留する（＝描画が打ち切られない）
2. サーバースクリプトが本物との相対座標を client_sync プロパティで毎tick同期する
3. リソースパックのMolangアニメーションが、モデルだけを本物の位置まで平行移動して描画する
4. 64ブロックを境に本物とゴーストが自動で切り替わる

エンティティ本体は動かさず「絵だけを遠くに描く」ため、当たり判定や
ゲームロジックには一切影響しません。

## クイックスタート

1. `example/` の `FarRenderDemo_BP` と `FarRenderDemo_RP` をワールドに導入
   （実験的なゲームプレイをONにする必要はありません）
2. 「FDRデモモブ」のスポーンエッグでモブを出す
3. 100〜200ブロック離れる — 通常なら消える距離でもモブが見え続けます

自分のアドオンに組み込む手順は
**[docs/implementation-guide.md](docs/implementation-guide.md)** を読んでください。
コピペで使えるテンプレートと、実機検証で確定した座標系の仕様、
開発中に踏んだ罠のリストが載っています。

## 既知の制約

- ゴーストはプレイヤーごとに生成されます（負荷はエンティティ数×プレイヤー数に比例）
- 歩行モーションなど「移動量から計算されるアニメーション」は遠距離では動きません
- 対象がチャンク読み込み範囲（シミュレーション距離）内にいる間だけ機能します

## MTC系列車アドオン向け

MTC系の列車素材については、アップロードするだけで自動変換できるツールを
公開しています: https://aorin.net/drawdistance-train/
（ドア・行先幕・走行音・カントの遠距離同期など、列車特化の追加機能入り）

## 名前について

ARD = **A**orin **R**ender **D**istance。開発時の内部名は FarRender / FDR で、
コードやドキュメント内の `fdr` 接頭辞はその名残です。
